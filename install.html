INSTALL APLIKASI ABSENSI KNE

Ikuti langkah berikut untuk install aplikasi di HP Anda:

1 Klik tombol "BUKA APLIKASI" di bawah
2 Klik titik tiga (⋮) di pojok kanan atas Chrome
3 Pilih "Tambahkan ke layar utama"
4 Klik "Tambahkan" atau "Install"
5 ✅ Selesai! Ikon KNEGO muncul di layar HP Anda
